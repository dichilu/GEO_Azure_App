# GEO 內容生成系統 (GEO Azure App)

**當前版本**: v1.24.6

## 專案簡介
這是一個部署於 Azure App Service 的全端網頁應用程式，專門用於產生與優化 SEO 友善的企業級產品內容。系統整合了 AI 內容生成策略，並允許使用者透過拖放參考文件與設定目標網址，快速產出符合品牌規範的行銷文案。

## 核心功能介紹

1. **AI 內容生成與優化引擎**
   - 選單順序：RBU（地區/事業群）＞生成內容（網站產品文案／廣告文案／SEO-GEO文章）＞目標優化引擎＞生成策略。
   - 目標優化引擎支援 Standard GEO, Gemini, Claude, ChatGPT, Perplexity；RBU 選 ACN（中國）時第一項同樣是 Standard GEO，其餘切換為文心一言、通義千問、DeepSeek、豆包。各引擎的語氣/結構客製化邏輯依2026 GEO/AEO實證研究校正，同時套用於產品文案與SEO/GEO文章生成（廣告文案尚未接入）。
   - 生成策略三種：智慧動態平衡、購買意圖優先、品牌聲量優先。
   - **SEO/GEO 文章（主文＋欉集叢集架構）**：兩階段生成——AI 先依 8 種內容角度評分規劃 3 套「主文＋3篇欉集」主題組合供選擇與微調標題，確認後正式生成 4 篇互相交叉引用的完整文章（含 TL;DR、H2/H3 目錄、FAQ）。
   - **搜尋補充佐證（Tavily）**：正式生成前，AI 先為 4 篇文章各規劃 3-5 個搜尋查詢（依該篇角度的資料需求程度自行決定要幾個；依文章角色決定查詢方向：定義型找權威定義/市場概覽，技術型找規格/評測數據，案例型找實務案例，比較型找評選標準），透過 `/api/tavily-search` 抓取外部佐證資料，生成時僅選用最相關的2-4個事實、以品牌語氣重新表達並自然帶出來源感（不逐句照抄、不附外部連結），提升內容時效性與可信度。
   - **每篇文章2張重點配圖（1200×628）**：AI寫文章的同時，額外產出2段構圖描述（寫實攝影風格，不含文字/Logo），透過 `/api/generate-image`（Gemini原生圖片模型）生成，瀏覽器端用畫布裁切縮放成精確1200×628並疊上AI標示浮水印，同步顯示於畫面預覽與嵌入Word匯出檔案。構圖決策依「主題優先→決定主體（不一定是產品）→文章有無提到應用場景→產品置於最低優先、非必要」的順序，避免4篇文章的圖片趨同成同一個「工廠+機械手臂+產品」畫面。單張圖片生成偶有失敗機率，失敗時該張留空不中斷流程。
   - **AI標示浮水印**：沿用「AI Content Center」專案同一份PNG素材與尺寸公式（畫布短邊×130/600、下與右邊界留白同步縮放），疊在每張生成圖右下角，不依賴生圖模型自行畫出標示文字。
   - **真實產品參考圖**：構圖若判斷該畫面需帶到研華硬體，AI會從已爬取的目標網址／同產品線參考網址內容中挑出真實產品照片（研華官網圖檔命名慣例含「Photo(Main)」等字樣），透過 `/api/fetch-image` 轉存後連同構圖描述一併送給生圖模型當參考圖，維持外觀（機殼形狀/接口配置/顏色）忠實度，非必要（畫面主體非硬體，或無對應產品照片）則不強制帶入。
   - **配圖禁止出現線材**：構圖描述與生圖模型固定指令兩層都明確禁止畫出任何線材/電線/插頭接觸或靠近研華硬體，避免生圖模型把接口類型畫錯或插頭懸空未接的錯誤細節；畫面主體以外、明顯不是研華產品的背景元素仍可有線材，不影響此限制。

2. **網頁內容爬蟲通道 (Scraping Proxy)**
   - 透過後端 `/api/scrape` 整合 Apify Website Content Crawler，突破前端瀏覽器的 CORS 跨網域限制與一般爬蟲的反爬蟲防護。
   - 自動抓取競品或參考網址的 Markdown 內容，做為 AI 生成的參考語境。

3. **企業知識庫與品牌規範**
   - 內建品牌憲法（Brand Guidelines）輔助參考，支援管理員密碼解鎖編輯。
   - 提供拖放區匯入外部參考資料（PDF, DOCX, XLSX, TXT 等）。

4. **行動版與多國語系支援**
   - **RWD 響應式設計**：支援桌面與手機版完美排版。
   - **多語系切換**：英文 (預設) ＞ 日文 ＞ 韓文 ＞ 繁體中文 ＞ 簡體中文，共 5 語系。介面語言與 AI 生成內容語言一致。

5. **後台追蹤與建議反饋**
   - 透過公司信箱登入，紀錄各部門使用頻率。
   - 系統建議反饋通道與管理員追蹤儀表板。

## 部署與運行
- **後端環境**: Node.js (Express)
- **部署平台**: Microsoft Azure App Service
- **部署方式**: Azure Zip Deploy（OneDeploy）—— 打包後以 `az webapp deploy --src-path appdeploy.zip --type zip` 上傳，建置行為由 `.deployment` 指定（`SCM_DO_BUILD_DURING_DEPLOYMENT=true`）
- **注意**: GitHub 與 Azure **無自動連動**。推送至 GitHub 僅進版控，不會更新正式站；上線需另外執行 Zip Deploy
- **正式站**: https://adv-ai-geo.azurewebsites.net （Resource Group: `Adv-Sales-Marketing-Services`）
